# jba-flood-events

Process JBA flood events for exposure analysis

## Setup

Requirements are Python and packages listed in `requirements.txt`.

To set up a virtual environment using venv:

```
python3 -m venv ./venv
. venv/bin/activate
pip install -r requirements.txt
```
